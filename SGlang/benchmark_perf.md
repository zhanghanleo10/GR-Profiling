# SGLang 性能测试记录（OneRec-1.7B）

- 基线版本：sglang-0.5.22（见 [test_case.md](./test_case.md)）
- 测试模型：OneRec-1.7B（固定，表中不再单列）
- 测试方式：每组配置重复测试 1000 次（1000 条请求 / 迭代），对每个分布型指标记录 min / P50 / P90 / P99 / mean / max
- 文档用途：SGLang 推理性能数据录入与汇总
- 创建日期：2026-10-28

---

## 1. 测试维度

| 维度 | 取值 | 说明 |
| --- | --- | --- |
| 机器平台 | L20 / L40 / H20 / A100 / H200 / B300 | GPU 型号 |
| 模型 | OneRec-1.7B | 固定 |
| SID | 3 / 4 / 5 / 6 / 7 / 8 | 语义 ID 长度（每候选 token 数） |
| BeamWidth | 32 / 64 / 128 / 256 / 512 / 1024 | Beam search 宽度（候选数） |
| 输入序列长度 | 128 / 256 / 512 / 1024 / 2048 / 4096 / 8192 / 10240 | 用户行为序列长度（token 数） |
| BatchSize | 1 / 2 / 4 / 6 / 8 / 16 | 并发请求批大小 |
| 重复次数 | 1000 | 固定值：每组配置测试 1000 次，表中不再单列 |

> 单次全量交叉组合为 6 平台 × 6 SID × 6 BeamWidth × 8 输入长度 × 6 BatchSize = 10368 组，按实际测试计划选点录入，每跑一组填一行。

## 3. 录入指标定义

每组配置固定测试 1000 次，统计量定义如下：

| 统计量 | 说明 |
| --- | --- |
| min | 1000 次中的最小值 |
| P50 | 中位数 |
| P90 | 90 分位数 |
| P99 | 99 分位数 |
| mean | 算术平均值 |
| max | 1000 次中的最大值 |

| 指标 | 单位 | 定义 | 记录方式 |
| --- | --- | --- | --- |
| E2E 时延 | ms | 单条请求端到端时延（prefill + decode） | 记录全部 6 项统计量 |
| 吞吐 | tok/s | 输出 token 吞吐（batch 内合计） | 记录全部 6 项统计量 |
| 峰值显存 | GB | 整个测试期间 nvidia-smi 峰值占用 | 单值，登记在测试索引表 |

> TTFT / TPOT 暂不记录，后续如需细分 prefill / decode 阶段再扩展。
> 输出 token 数一般由 BeamWidth × SID 决定，如有特殊截断 / 长度请在备注中说明。

## 5. 分平台数据录入明细

填写说明：每组测试先在「测试索引表」登记一行（含峰值显存），再在 E2E / 吞吐两张统计表中按**同一序号**填入 1000 次测试的统计量；统计量列顺序统一为 min / P50 / P90 / P99 / mean / max。

示例（索引表）：`| 1 | 5 | 256 | 1024 | 4 | 68.2 | C001 | 2026-10-28 | —— |`

### 5.1 L20

截至 2026-10-29 05:33（北京时间）停止时的结果快照：136 组成功、28 组 CUDA OOM；余下组合尚未完成。结果来自单卡 GPU 0，配置 C001。

- 每个成功配置完成 5 轮预热、1,000 条实际 HTTP 请求；BatchSize 是闭环并发请求数，E2E 为客户端单请求的完整响应时间（包含 HTTP 开销）。
- 吞吐分位数按每个完整批次的实际返回候选 token 总数除以该批次墙钟时间计算；不足 BatchSize 的末批不纳入分位数。因此每组有 1,000 个时延样本，但吞吐样本数为 `floor(1000 / BatchSize)`，不是 1,000 个批次。聚合吞吐另用所有返回 token 总数除以测量窗口总时长。
- 峰值显存通过 `nvidia-smi` 每 0.5 秒采样，数值包含服务预分配的显存，可能低于瞬时真实峰值，单位 GiB（MiB ÷ 1024）。
- 输入采用四条合成历史轮换；长度超过 2048 的输入由 2048-token 历史重复扩展。调用 SGLang `/generate`，`beam_width=n=BeamWidth`，输出上限为 SID，禁用 radix cache；本次数据均为输出长度 3，未进行 SID catalog 约束或有效性验证。
- 原始数据和日志在 L20 主机 `/home/z00469465/sglang-l20-bench-20261028/matrix/`。下表不包含中断或未完成的尝试。
